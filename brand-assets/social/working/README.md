# Editables de campañas

Crea una subcarpeta por campaña y conserva aquí los duplicados editables de `templates/originals/`. Ejemplo: `2026-11_presentacion/2026-11-01_presentacion_feed_v01.svg`.

Guarda las exportaciones correspondientes en `social/exports/` dentro de una carpeta con el mismo nombre de campaña. No sobrescribas las plantillas base.
